# Softer sound and field details

Soft sound adds a remembered quiet level alongside mute. Changing levels keeps a
muted room silent. The master gain eases toward the new level; room state, roles
and the canvas engine keep their existing owners. Autofill follows day/night colors.

- [Desktop controls](connection-desktop.png)
- [Phone controls](connection-mobile.png)

Browser journeys check choosing and remembering the level. An instrumented audio
context checks quiet/normal gain and mute behavior. Captures use an isolated local
room. Actual speaker volume, physical backgrounding and native autofill remain
device checks.
