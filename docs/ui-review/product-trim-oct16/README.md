# Product simplification — October 16

The room has one sound on/off button. Cues use the quiet master gain, and the existing mute preference survives reloads. The extra Soft/Normal button, louder preset, preference reader/writer and unused styles were removed. Room content and seat permissions are unchanged.

The review also covered recent additions across the other apps. Accounts repeats each passkey's last-use time only once and labels the actual backup flag. Everything Is Fine drops citation export while retaining pinned-event sharing, clipboard recovery, provider attribution and the individual readings.

| App       | Recent additions retained                                    | Reason                                                                                 |
| --------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| worth     | Cover framing, ranking exports, browsing context             | They preserve useful content and make an existing collection easier to use.            |
| owewell   | Amount parsing, rounding explanations, dated exports         | They prevent money-entry mistakes and make records understandable.                     |
| bloomnote | Readable text option, complete printed notes, share recovery | They help the recipient read and keep the actual message.                              |
| wherever  | Voting safeguards, stable details, honest travel estimates   | They prevent accidental choices and misleading planning information.                   |
| iguess    | Input composition handling and matching reaction artwork     | They preserve chat text and support the game’s established reactions.                  |
| portfolio | Screenshot history, navigation and contrast fixes            | They make existing work easier to inspect without introducing another product feature. |

This is a review of the recent additions, not a new feature backlog. New controls need a specific job in an existing flow. No product feature was added during this pass.

The complete verification command passed on a sequential rerun after a local Worker startup timeout. The sound regression rejects the old louder gain and passes after restoring the quiet gain. Desktop and phone captures were inspected in both palettes, including keyboard focus and horizontal overflow. Captures wait for canvas artwork after a resize. Physical-device sound and vibration were not tested.
